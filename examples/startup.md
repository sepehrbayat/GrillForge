# Example: Startup Idea

## Prompt

```text
Use GrillForge to pressure-test this idea:
An AI assistant that summarizes sales calls for small agencies.
```

## Likely critical claims

- Agencies experience enough pain from manual notes.
- They will permit access to sensitive calls.
- Existing meeting tools are not already good enough.
- Summaries improve follow-up behavior.
- Teams will pay for the outcome.

## Useful proof skewer

Run the service manually for five agencies using uploaded recordings. Require a second-week request or payment as the pass condition.

## Possible verdict

`PROBE` until trust, repeated use, and willingness to pay are demonstrated.
