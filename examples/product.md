# Example: Product Feature

## Prompt

```text
Run GrillForge on this feature before implementation:
Add an AI-generated daily dashboard to our project-management app.
```

## Questions GrillForge should force

- Which decision becomes easier because of this dashboard?
- What current behavior proves users want a daily summary?
- What happens when the generated interpretation is wrong?
- Why is this better than a notification or saved view?
- Which usage signal would justify permanent product complexity?

## Possible proof skewer

Deliver the summary manually to 20 active users for one week. Pass only if at least 30% open it repeatedly and take a measurable follow-up action.
